\begin{denotation}[6.5cm]

\item[CNN] 卷积神经网络 (Convolutional Neural Network)
\item[IFM] 输入特征图 (Input Feature Map)
\item[OFM] 输出特征图 (Output Feature Map)
\item[PSUM] 部分和 (Partial Sum)
\item[DSP] 数字信号处理单元 (Digital Signal Processing slice)
\item[BRAM] 块随机存取存储器 (Block RAM)
\item[LUT] 查找表 (Look-Up Table)
\item[PE] 处理单元 (Processing Element)
\item[FSM] 有限状态机 (Finite State Machine)
\item[AXI] 高级可扩展接口 (Advanced eXtensible Interface)
\item[DMA] 直接存储器访问 (Direct Memory Access)
\item[$K_{\text{total}}$] 展开后输入通道总维度，$K_{\text{total}} = C_{in} \times K_h \times K_w$
\item[$K_{\text{TILE}}$] 单次 K 分块处理的输入 lane 数
\item[$C_{\text{out}}$] 输出通道数
\item[$\text{COUT}_{\text{TILE}}$] 单次计算覆盖的输出通道数
\item[$H, W, C$] 特征图高度、宽度、通道数
\item[$K_h, K_w$] 卷积核高度、宽度
\item[$oy, ox$] 输出特征图空间坐标
\item[GEMM] 通用矩阵乘法 (GEneral Matrix Multiply)
\item[FPGA] 现场可编程门阵列 (Field Programmable Gate Array)
\item[XCK26] Xilinx Kria K26 核心 FPGA 器件型号
\item[WNS] 最差负时序裕量 (Worst Negative Slack)
\item[HWC] 高度-宽度-通道 (Height-Width-Channel) 内存布局

\end{denotation}
