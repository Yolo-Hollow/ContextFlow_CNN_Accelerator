\noindent\textbf{Abstract}\quad
This paper presents \LASA, a layer-adaptive HWC-streaming systolic accelerator
for all thirteen convolution layers of YOLOv3-tiny. Its 18-way reduction input
and 16-column dual-output structure provides up to 576 INT8 MACs per cycle.
On-chip HWC materialization and replay reuse each input tile across reduction
passes, while tagged contexts, weight preloading, fast handoff, continuous
partial sums, and a decoupled drain suppress pass- and layer-boundary bubbles.
Implemented at 200 MHz on XCK26/KV260, the system achieves
\PLEffectiveGOPS{} GOPS and \ResidentFPS{} FPS at batch one and
416$\times$416 input. Convolutions execute in programmable logic; tensor
transforms and dual-scale decode/NMS execute on the A53 processors. Integer
conformance is byte-exact for \NodeRecords{} node records, and 5000-image
raw-head metrics match the host INT8 reference.\par

\vspace{2mm}
\noindent\textbf{Keywords}\quad edge computing; MPSoC; systolic array;
HWC streaming; YOLOv3-tiny; cross-pass scheduling; integer inference\par
