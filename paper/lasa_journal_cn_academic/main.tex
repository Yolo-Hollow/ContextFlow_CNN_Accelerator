\noindent{\heiti 摘\quad 要\quad}
固定规模阵列执行长 $K$ 卷积时，需要将一次卷积分解为多个 $K$ 维计算轮次
和输出通道块；若输入随这些计算上下文反复由 DDR 送入，外存流量与边界空泡
将随二维分块成倍放大。本文提出片上物化重放脉动阵列 \LASA，将软件可见的
HWC 输入一次转换为阵列窗口，并在后续计算轮次中从片上缓存重放，使片外输入
流量由计算轮次数量解耦。LASA 进一步通过权重提前装载、连续部分和反馈和
上下文直接切换重叠计算边界，同时以缓冲区唯一占用、数据不覆盖和顺序提交
保持反压下的确定性。系统在 XCK26/KV260 上以 200 MHz 运行完整双尺度
YOLOv3-tiny，取得 \ResidentFPS{} FPS、\PLEffectiveGOPS{} GOPS 和
\ArrayUtilization{}\% 阵列利用率；resident 平均延迟为 \ResidentMeanMs{} ms。
128 张图的 \NodeRecords{} 条整数节点记录全部与主机参考逐字节一致，5000 张
COCO val2017 的双检测头指标完全一致；当前 INT8 参数的 AP50:95/AP50 为
14.304\%/30.212\%，量化参数训练与本文架构贡献相互独立。\par

\noindent\textbf{Abstract}\quad
Long-reduction convolutions are partitioned into many reduction passes and
output-channel blocks on a fixed-size array.  Re-streaming the same input tile
for these contexts amplifies off-chip traffic and exposes a boundary bubble at
every pass.  LASA materializes an HWC tile once and replays the resulting
windows on chip, while context scheduling overlaps weight loading, partial-sum
feedback, and the next computation.  At 200 MHz on XCK26/KV260, the complete
dual-head YOLOv3-tiny system achieves \ResidentFPS{} FPS,
\PLEffectiveGOPS{} GOPS, and \ArrayUtilization{}\% array utilization.  All
\NodeRecords{} integer node records from 128 images are byte-exact against the
host reference, and raw-head metrics over 5000 COCO validation images match
exactly.\par

\vspace{2mm}
\noindent\textbf{Keywords}\quad edge computing; MPSoC; systolic array;
materialize and replay; context scheduling; YOLOv3-tiny\par
